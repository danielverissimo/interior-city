1º ADD 
mods / update / x64 / dlcpacks
	
 - Create a folder named  serv_electricscooter  within the mass dlcpacks
 - Drag the contents of the .zip folder into the created folder.


/////////////////////////////////////
2º ADD
 mods / update / update.rpf / common / data
	
 - Drag the following files "DLCLIST.XML" and "EXTRATITLEUPDATE.META" to the Desktop, 
 then open with Notepad, adding the following lines of code.
	
 “DLCLIST.XML”
	
 <Item>dlcpacks:/serv_electricscooter/</Item>
	
 “EXTRATITLEUPDATE.META”
	
 <Item type="SExtraTitleUpdateMount">
	<deviceName>dlc_serv_electricscooter:/</deviceName>
	<path>update:/dlc_serv_electricscooter/</path>
 </Item>

 Save the two edits and resubmit to the "Date" folder in the path mods / update / update.rpf / common / data
